# Temperature Converter

A simple web project created for my Day 5 Web Development Internship at Veda Technology. It converts temperatures between Celsius, Fahrenheit, and Kelvin.

## Live Preview

https://wadityasingh.github.io/day-5-temperature-converter/

## Features

- Converts Celsius, Fahrenheit, and Kelvin.
- Updates the other values when a temperature is entered.
- Checks invalid temperature values.
- Shows a temperature status.
- Includes a Reset All button.
- Works on mobile and desktop screens.

## Temperature Examples

| Celsius | Fahrenheit | Kelvin |
|---:|---:|---:|
| 0°C | 32°F | 273.15 K |
| 25°C | 77°F | 298.15 K |
| 38°C | 100.4°F | 311.15 K |
| 100°C | 212°F | 373.15 K |

## README.md – Project information

How to Use

Open the website using the Live Preview link.

Enter a temperature in any input field.

The other two values update automatically.

Click Reset All to clear the fields.

## Colour Design

The website uses a light background, dark text, and blue accents for a clean and readable look. Input borders highlight when selected, and error messages appear when an invalid temperature is entered.
